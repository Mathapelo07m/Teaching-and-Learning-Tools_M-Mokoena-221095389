⬆ Tap a part to see what it does.

Monitor — output

An output device that shows what the computer is doing on screen.

CPU — processing

The “brain” of the computer. It processes instructions and does the calculations.

RAM — memory

Temporary memory the computer uses while working. It clears when the power is off.

Storage — storage

Keeps your data and programs for later, even when switched off (hard drive, SSD, flash drive).

Keyboard — input

An input device used to type text and commands into the computer.

Mouse — input

An input device used to point, click and select on the screen.
