Think in Algorithms: Build a Quiz Game

Plan it in plain steps, then build it in Scratch.

Made with Scratch
Goal: plan an algorithm, then turn it into a working quiz game using sequence, a loop and a condition. The Scratch offline editor means this works even without steady internet.

1. Plan your algorithm (pseudocode)

Here is a worked example. Write your own version for your topic below.

START
  set score to 0
  ask “What is 5 + 7?”
  IF answer = 12 THEN
      say “Correct!”  and  add 1 to score
  ELSE
      say “Try again”
  REPEAT for the next 4 questions
  say “Your score is” + score
END
