ICT Terms Match-Up

Match each term to its meaning — a quick warm-up before the test.

Made with Wordwall
How to play: read the term, say the meaning out loud or write it, then tap to check. In class this runs as a live Wordwall match-up game (and a “random wheel” for revision).
Hardware
The physical parts of a computer that you can touch — like the keyboard, screen and mouse.
Software
The programs and instructions that tell the computer what to do — like a browser or a word processor.
Input device
Hardware used to put data into the computer — keyboard, mouse, microphone, scanner.
Output device
Hardware that shows or produces results — monitor, printer, speakers.
Storage device
Hardware that keeps data for later use — hard drive, SSD or flash drive.
CPU
The “brain” of the computer that processes instructions and does the calculations.
RAM
Temporary memory the computer uses while it is working; it clears when the power goes off.
Operating system
The main software that manages the whole computer — for example Windows, macOS or Linux.
